# 🚇 Метроша — голосовой помощник для Корпоративного Университета Транспортного Комплекса Москвы

Интеллектуальный чат-бот на базе **GigaChat** и **SaluteSpeech** от Сбера. Отвечает на вопросы студентов и абитуриентов, озвучивает ответы, поддерживает голосовой ввод (работает в браузерах на WebKit) и имеет интерактивного маскота.

---

## 📦 Функционал

- Текстовый и голосовой ввод вопросов
- Быстрые кнопки с популярными темами (расписание, льготы, специальности и т.д.)
- Генерация ответов через GigaChat
- Синтез речи (мужской/женский голос) через SaluteSpeech
- Тёмная/светлая тема (автоматически подстраивается под систему)
- Маскот с информацией о Московском метрополитене
- Автоматическая очистка старых аудиофайлов (каждый час)

---

## 🛠 Технологии

- **Backend**: Python 3, Flask
- **AI**: GigaChat (текст), SaluteSpeech (озвучка)
- **Frontend**: HTML, CSS, JavaScript (vanilla)
- **Хранение**: локальные файлы (аудио), `localStorage` (настройки)

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone <your-repo-url>
cd <project-folder>
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
```

Активация:
- **Windows**: `venv\Scripts\activate.bat`
- **Linux/macOS**: `source venv/bin/activate`

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env`, указав свои данные:

```
GIGACHAT_CREDENTIALS=your_base64_credentials
SPEECH_CLIENT_ID=your_client_id
SPEECH_CLIENT_SECRET=your_client_secret
AUDIO_DIR=audio
DEBUG=True
```

> **Где взять ключи?**
> - `GIGACHAT_CREDENTIALS` – base64-строка от пары `client_id:secret` для GigaChat (получить в SberDevices).
> - `SPEECH_CLIENT_ID` и `SPEECH_CLIENT_SECRET` – учётные данные для SaluteSpeech (там же).
> - Все ключи выдаются при создании приложения в [SberDevices Console](https://developers.sber.ru/).

### 5. Запустите сервер

```bash
python main.py
```

Откройте в браузере: [http://localhost:5000](http://localhost:5000)

## 🌐 Использование

- Напишите вопрос в поле ввода или нажмите на микрофон для голосового запроса.
- Выберите пол голоса (мужской/женский) для озвучки ответов.
- Включите/выключите озвучку переключателем.
- Используйте кнопки с популярными вопросами для быстрого доступа.
- Кликните на маскота, чтобы узнать интересные факты о Московском метро.
- Переключайте тему оформления (🌙/☀️) – настройка сохраняется в браузере.

## 🔧 API эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная страница |
| POST | `/api/chat/text` | Отправка запроса. Принимает JSON `{"query": "...", "voice": "male/female"}`. Возвращает `textResponse` и `audioUrl` (если синтез удался). |
| GET | `/audio/<filename>` | Отдаёт WAV-файл |
| GET | `/api/health` | Проверка состояния сервера |

## 🧹 Очистка аудиофайлов

Все сгенерированные аудио хранятся в папке `audio/` и автоматически удаляются, если их возраст превышает **1 час**. Это предотвращает переполнение диска.

## ❗ Возможные проблемы и их решение

### 1. Ошибка прокси (`Connection refused`, `SOCKS support`)

Если вы используете VPN или прокси, переменные окружения `http_proxy`/`https_proxy`/`all_proxy` могут мешать доступу к API Сбера. В проекте все запросы к внешним API выполняются через сессию с параметром `session.trust_env = False` – это полностью отключает использование системных прокси. Если ошибка всё ещё возникает, проверьте, что у вас не установлены переменные окружения, переопределяющие поведение.

### 2. Ошибка 402 от SaluteSpeech (`Payment Required`)

Эта ошибка означает, что ваш аккаунт в SberDevices не имеет активного тарифа для синтеза речи или исчерпал бесплатные кредиты.

**Решение:**
- Зайдите в [SberDevices Console](https://developers.sber.ru/console), выберите своё приложение.
- Перейдите в раздел «Тарифы и платежи» и проверьте баланс.
- Пополните баланс или переключитесь на тариф, поддерживающий TTS.
- Если вы используете пробный период, возможно, нужно активировать промокод или подождать обновления лимитов.

> Примечание: если аудио не критично, бот продолжит работать в текстовом режиме (ошибка не прерывает работу).

### 3. Голосовой ввод не работает

- Голосовой ввод работает только в браузерах на движке **WebKit** (Chrome, Safari, Edge). Убедитесь, что разрешили доступ к микрофону.
- В Firefox поддержка Speech Recognition ограничена – рекомендуется использовать Chrome.

### 4. Аудио не воспроизводится

- Проверьте, включена ли озвучка (переключатель).
- Браузеры требуют жеста пользователя для первого воспроизведения – кликните по странице перед отправкой запроса.

## 🛠 Для разработчиков

- Изменить системный промпт GigaChat можно в `app/gigachat.py` (переменная `SYSTEM_PROMPT`).
- Параметры голосов (`voice`, `emotion`, `speed`) – в `app/speech.py`.
- Все настройки вынесены в `.env`, не редактируйте код для смены ключей.
